{%- comment -%} FAQPage markup, generated from the page's own `## FAQ` section. See the faqPairs filter in eleventy.config.js for the parsing rules and why this is generated rather than hand-written. `page.rawInput` is the markdown source of the page being laid out — the same value md-mirror.liquid mirrors — so the questions and answers here are byte-identical to the ones a reader sees, which is what Google's "the answer must be present on the page" requirement actually asks for. Two or more pairs required. FAQPage with a single question is a heavier claim than it is worth, and a page with one answered question is not an FAQ. Included by post.html and docs.html. NOT by mcp.html: mcp/security.md keeps its own hand-written block because its questions sit under ordinary section headings rather than in an `## FAQ`, which the filter deliberately does not match. {%- endcomment -%} {%- assign faqList = page.rawInput | faqPairs: faqPage -%} {%- if faqList.size > 1 -%} {%- endif -%}
