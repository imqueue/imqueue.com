{%- comment -%} Cookie-consent bar, included on every page of both editions from base.html. `hidden` is the default and js/consent.js decides: it shows the bar only when localStorage holds no decision yet, and the footer's "Cookie settings" link brings it back afterwards. So with JavaScript off the bar never appears — and neither does any analytics tag, because head.html parks those as `type="text/plain"` and only consent.js can turn them into real scripts. No consent, no measurement, in every case including the broken ones. Decline is listed first and given the same size and weight as Accept: refusing has to be exactly as easy as agreeing, or the consent is not freely given. Styles live in _shared/css/base.css (.cc*) and use only tokens both themes define, so the bar takes the terminal or flux palette automatically. {%- endcomment -%}

Cookies Google Analytics and Microsoft Clarity help us see which pages work and which confuse — Clarity also records page interaction. They load only if you accept; decline and nothing is set. Details in the privacy policy, alongside the terms of use and how to reach support.
