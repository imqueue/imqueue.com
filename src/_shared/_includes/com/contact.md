# Contact @imqueue

Source: https://imqueue.com/contact/

**support@imqueue.com** reaches the maintainers directly. The form at
<https://imqueue.com/contact/> goes to the same mailbox and accepts attachments —
a screenshot or a log.

Use it for general enquiries, support questions, documentation problems, and
anything that is not a licensing quote.

## Faster routes for specific things

- **A licensing quote** — <https://imqueue.com/pricing/> captures what is needed
  to answer in one round trip.
- **A bug or a feature request** — file it in the affected package's own
  repository under <https://github.com/imqueue>, which is where its maintainers
  are looking.
- **A security vulnerability** — do **not** use a public form or a public issue.
  Report it privately; see <https://imqueue.org/support/>.
- **A documentation question** — the docs are on <https://imqueue.org>, and
  <https://imqueue.org/llms.txt> indexes them for machine readers.
