{%- comment -%} The contact form, shared by /contact/ on both editions. One markup source rather than one per skin: the fields, the validation, the honeypot and the attachment rules are identical on both sites, and two copies of a form that posts to the same endpoint is two places for a validation rule to drift. The look is not shared — `cf-*` is styled from theme tokens in base.css and re-tuned for flux in com/css/flux.css, the same way the docs sidebar is, so each site renders it in its own design while the behaviour stays one implementation (site.js, [data-contact-form]). Posts JSON to /api/message (functions/api/message.js). Works only with JavaScript: attachments have to be read and base64-encoded client-side, and a no-JS fallback that silently dropped them would be worse than the mailto link the page also offers. {%- endcomment -%}
