    {%- comment -%} Six pages used to emit `Blog @id .../blog/#blog` — /blog/ plus five /blog/page/N/ — each with `url: /blog/` and a DIFFERENT `blogPost` array. One @id making six different membership claims about the same entity, which is the sort of contradiction that makes a graph worth less than no graph. Split by role, which is what the two node types are for: * /blog/ owns the `Blog` entity and its `blogPost` array. One node, one page. * every page, including /blog/, also emits a `CollectionPage` at its OWN url with the posts on that page as an ItemList — the same pattern topics.html already uses. `isPartOf` ties it back to the one Blog node. So a paginated page now says "I am page 4 of this collection, and here is what is on me", instead of claiming to be the collection. {%- endcomment -%} {%- assign blogId = siteUrl | append: "/blog/#blog" -%} {%- if pagination.pageNumber == 0 %} {%- endif %}
